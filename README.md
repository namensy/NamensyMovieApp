# Movie Search App

A React application that helps users discover and find movies they'll enjoy. Built with React and Vite for optimal performance.

## Features

- Search for movies with real-time results
- View trending movies with rankings
- Browse through a comprehensive movie catalog
- Responsive design with a modern UI
- Loading states and error handling

## Tech Stack

- React 
- Vite
- CSS for styling
- API integration for movie data
